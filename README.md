# Missouri Route Maker

Missouri Route Maker is an offline-first Progressive Web Application (PWA) for managing thousands of saved places and creating optimized multi-stop driving routes throughout Missouri.

## Features

- Offline-first
- Progressive Web App (PWA)
- IndexedDB local storage
- MapLibre GL JS
- OpenStreetMap
- OSRM Routing
- GPS Follow Me
- Route optimization
- Import/Export
- Responsive design

## Technology

- HTML5
- CSS3
- JavaScript (ES6 Modules)
- IndexedDB
- Service Worker
- MapLibre GL JS
- OpenStreetMap
- OSRM
